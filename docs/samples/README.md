# Образцы документов

## word-demo.docx

Документ для проверки и показа просмотра Word: шрифты, выделение текста, выравнивание, табуляция, отступы, списки, таблицы, рисунки, диаграммы, длинные слова, колонтитулы, сноска и две колонки. У каждого раздела есть плашка «Что проверить» с тем, на что смотреть.

Как показать: импортировать файл в файловый менеджер приложения и открыть. Кнопка «Открыть в другом приложении» в просмотрщике открывает тот же файл в Word или WPS для сравнения.

### Что показывается

Проверено на OpenDocument.core 7.7.0 с правками и CSS приложения в Chromium с экраном телефона; эталон — LibreOffice.

### Как пересобрать

Скрипты в `word-demo-src/`. Нужны Node.js с пакетом `docx` и Python 3.

```bash
cd docs/samples/word-demo-src
python3 make_pngs.py /tmp/word-demo
node make_demo.js /tmp/word-demo /tmp/word-demo/base.docx
python3 add_charts.py /tmp/word-demo/base.docx ../word-demo.docx
```

`make_demo.js` собирает документ без диаграмм, `add_charts.py` вставляет две диаграммы Word с кэшем данных, как их сохраняет Word, и исправляет то, что схема Word не принимает у пакета `docx`.
