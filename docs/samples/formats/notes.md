# Заметки по объекту

Обычный абзац с **жирным**, *курсивом* и `кодом`. Ссылка: [пример](https://example.com).

## Что проверить

1. Датчики температуры
2. Питание
   - основное
   - резервное
3. Связь

| Датчик | Значение | Норма |
|---|---:|---|
| Температура | 45 °C | 5–60 |
| Напряжение | 220 В | 198–242 |

> Цитата: проверять раз в смену.

```
status = read_sensor("temperature")
```
