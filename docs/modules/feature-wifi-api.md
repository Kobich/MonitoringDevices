# Модуль `:feature:wifi:api`

Модуль публикует внешний UI-контракт Wi-Fi фичи. Он не содержит ViewModel, scanner-зависимостей и Android Wi-Fi API.

## Контракт

`WifiFeatureApi` предоставляет composable-функцию `WifiScreen(modifier)`. `app` использует этот интерфейс, не зная о внутренней структуре Wi-Fi экрана.

## Файлы

| Файл | Назначение |
|---|---|
| `WifiFeatureApi.kt` | Публичный Compose-контракт фичи. |

Изменять контракт следует только при необходимости передавать данные или callbacks между `app` и Wi-Fi фичей. Внутренние UI-состояния сюда не выносятся.
